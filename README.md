# 자라섬 키우기 (JARASUM LIFE)

캐릭터별 일상과 선택형 성장 스토리를 플레이하는 웹게임 프로토타입.

## 실행
- `index.html`을 브라우저에서 열면 실행됩니다.
- GitHub Pages에서 배포할 수 있습니다.

## 캐릭터
다래, 루뭉, 으네, 돗챠, 하밍, 시로, 빅윈, 뚜닝, 도담히.

## 현재 프로토타입
- 캐릭터 선택
- 일상 행동 및 간단한 스토리 선택
- 상태/일정/채팅 화면
- 브라우저 저장 데이터

## 개발 예정
- 캐릭터별 장편 루트와 분기
- 복수 엔딩
- 공식 캐릭터 이미지와 배경
- 상황형 미니게임
